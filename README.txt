CHARGEFLOW PROTOTYPE
====================

WHAT IS INCLUDED
- index.html: page structure and all prototype screens
- styles.css: responsive visual design
- app.js: map markers, navigation, reservation modal, charging animation and rewards interactions

HOW TO RUN
1. Put all three files in the same folder.
2. Open PowerShell in that folder.
3. Run: start index.html

No dependencies, extensions, npm packages, backend or internet connection are required.

DEMO JOURNEY
1. Start on Home.
2. Select "Find my best charger".
3. Click a marker on the UK map.
4. Reserve the charger.
5. Open "My journey".
6. Start the journey.
7. Show the animated charging session.
8. Open Rewards and Impact.

IMPORTANT
All locations, availability, prices, performance scores, customer data and impact figures are illustrative prototype data for a dummy case study. They are not live network information.
